NounRemember
PublisherSends to an exchange, never "into" a queue
ExchangeRoutes by type + bindings to zero or more queues
BindingThe rule linking an exchange to a queue
QueueHolds messages until a consumer takes them
ConsumerThe worker process that handles the message

Rules of thumb

  • Keep in the request what the customer must know now (payment result); queue the rest.
  • Unroutable message: dropped or returned, depending on publisher options.
  • Default exchange: nameless; queues auto-bind by queue name.
