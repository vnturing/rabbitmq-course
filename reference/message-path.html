NounRemember
PublisherSends to an exchange, never "into" a queue
ExchangeRoutes by type + bindings to zero or more queues
BindingThe rule linking an exchange to a queue
QueueHolds messages until a consumer takes them
ConsumerThe worker process that handles the message

Exchange types (Lesson 2)

TypeRule
FanoutIgnores the key; copy to every bound queue
DirectBinding key equals routing key
TopicPattern on dotted words: * = exactly one word, # = zero or more
HeadersMatches on message headers; ignores the key
  • Topic with only # acts like fanout; topic without wildcards acts like direct.
  • Two matching bindings on one queue still deliver one copy.

Laravel driver (Lesson 3)

Setting or commandRemember
queueDefault queue name (otherwise default)
options.queue.exchange / exchange_typePublish to this exchange; no routing key set means the queue name is used
BindingsWith a custom exchange you probably declare queue bindings yourself
queue:workbasic_get; can read several queues
rabbitmq:consumebasic_consume; ~2x faster; one queue only
RABBITMQ_WORKER=horizonHorizon support
job optionYour own RabbitMQJob class for foreign messages

Rules of thumb

  • Keep in the request what the customer must know now (payment result); queue the rest.
  • Unroutable message: dropped or returned, depending on publisher options.
  • Default exchange: nameless; queues auto-bind by queue name.
